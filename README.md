# AluGames

Página de aluguel de boardgames onde cada jogo pode ser marcado como alugado ou devolvido através de um clique.

[![ALUGAR AGORA](https://img.shields.io/badge/ALUGAR%20AGORA-1875E8?style=for-the-badge)](https://raphael-bezerra.github.io/alugames/)

## 🏷️ Sobre

Projeto desenvolvido durante os estudos de Lógica de Programação e JavaScript.

O objetivo é praticar manipulação do DOM e eventos de clique, atualizando o status visual e o texto do botão dinamicamente.

## 🧠 Conceitos praticados

- JavaScript
- manipulação do DOM
- `classList`
- eventos de clique

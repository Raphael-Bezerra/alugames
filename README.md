# AluGames

[![Ver demo](https://img.shields.io/badge/Ver-Demo-00F4BF?style=for-the-badge)](https://raphael-bezerra.github.io/alugames/)

## Sobre

Página de aluguel de boardgames onde cada jogo pode ser marcado como alugado ou devolvido através de um clique, atualizando o status visual e o texto do botão dinamicamente.

## Funcionalidades

- Alternar status de um jogo entre "disponível" e "alugado";
- Atualização visual da capa do jogo conforme o status;
- Atualização do texto e estilo do botão de ação.

## Conceitos praticados

- Manipulação do DOM;
- Seleção de elementos por `id` e classes;
- Manipulação de classes CSS via JavaScript (`classList`);
- Eventos de clique.
